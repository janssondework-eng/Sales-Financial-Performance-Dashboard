# Project Overview

This Power BI project is a portfolio case study for business intelligence, sales analytics and financial performance reporting.

The report is built as a management dashboard rather than a raw exploratory report. It focuses on a small set of business questions:

- how much revenue and profit the business generated
- which regions and categories drive performance
- how customer segments are distributed
- which products and customers should receive management attention
- how profitability changes across regions, products and time

## Audience

The target audience is a business stakeholder, sales manager, financial analyst or BI/reporting manager who needs a fast overview of performance and drilldown paths for follow-up analysis.

## Dashboard Pages

### Executive Dashboard

The executive page combines KPI cards, trend analysis and ranked bar charts. It answers the question: "What is the overall business performance and where is it coming from?"

### Customer Analytics

The customer page focuses on customer count, regional customer distribution, customer type segmentation and top customers by revenue. It supports decisions about customer prioritization and segmentation.

### Financial Analytics

The financial page compares revenue, profit, cost and margin. It helps separate high-revenue areas from high-margin areas.

## Portfolio Value

This project demonstrates:

- Power BI report design
- star-schema modeling
- KPI definition
- DAX measure logic
- segmentation analysis
- financial performance interpretation
- executive dashboard storytelling

## Main Result

The dashboard turns a sales dataset into three decision-ready views: executive summary, customer analytics and financial analytics.
