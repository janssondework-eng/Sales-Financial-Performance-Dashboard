# Sales & Financial Performance Dashboard

[English version](README.md)

Интерактивный Power BI проект для портфолио по анализу продаж, прибыльности, клиентов и региональной эффективности.

Дашборд рассчитан на управленческую аудиторию: он собирает выручку, прибыль, маржу, заказы, клиентские сегменты, регионы и топ продуктов в несколько страниц, готовых для принятия решений.

## Краткое резюме

- Общая выручка: 24.95M
- Общая прибыль: 10.50M
- Общие затраты: 14.45M
- Маржа прибыли: 42.10%
- Заказы: 5K
- Клиенты: 500
- Регионы: 8
- Ведущий регион по выручке: Москва
- Сильнейшие категории: Skincare и Hair Care

## Страницы дашборда

### Executive Dashboard

Управленческий обзор с KPI-карточками, трендом выручки, выручкой по регионам, выручкой по продуктовым категориям и топом продуктов.

![Executive Dashboard](screenshots/executive_dashboard.png)

### Customer Analytics

Клиентская страница с количеством клиентов, новыми клиентами, региональным распределением, топом клиентов по выручке и сегментацией по типу клиента.

![Customer Analytics](screenshots/customer_analytics.png)

### Financial Analytics

Финансовая страница с выручкой, прибылью, затратами, маржей, трендом revenue vs profit, маржей по регионам, прибылью по категориям и топом продуктов по прибыли.

![Financial Analytics](screenshots/financial_analytics.png)

## Модель данных

Дашборд использует подход star schema:

- `Sales` как fact table
- `Customers` как customer dimension
- `Products` как product dimension
- `Calendar` как date dimension

## Основные метрики

| Метрика | Назначение |
|---|---|
| Revenue KPI | общий показатель продаж |
| Profit KPI | прибыль после затрат |
| Total Cost | база затрат для анализа прибыльности |
| Profit Margin KPI | прибыль как доля выручки |
| Orders KPI | объем заказов |
| Customers KPI | размер клиентской базы |
| Regions Count | региональный охват |

## Ключевые выводы

### 1. Москва - основной рынок по выручке

Москва лидирует по выручке среди регионов, поэтому она должна оставаться приоритетным рынком для удержания, планирования ассортимента и анализа высокоценных клиентов.

### 2. Skincare и Hair Care формируют основную категорийную эффективность

Эти категории доминируют в срезах по выручке и прибыли. Они являются естественными кандидатами для оптимизации маржи и планирования промо.

### 3. Сегментация клиентов поддерживает таргетированные действия

Клиентская страница разделяет B2B Key Account, B2B Medium, B2B Small и Retail клиентов, что помогает строить разные коммерческие стратегии.

### 4. Прибыльность нужно читать вместе с выручкой

Financial Analytics разделяет тренды выручки и прибыли, помогая менеджменту не фокусироваться только на объеме продаж, когда важны изменения маржи.
